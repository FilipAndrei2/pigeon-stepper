# Install Deps
If you want to compile from cli, you will need to install the necessary packages
On arch:
```bash
sudo pacman -Syu

sudo pacman -S \
  arm-none-eabi-gcc \
  arm-none-eabi-newlib \
  cmake \
  ninja \
  git \
  base-devel   
```
